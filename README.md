# TestClass Exercise

Projeto desenvolvido para estudo de testes automatizados com Java e Spring Boot.

## Tecnologias

* Java 21
* Spring Boot
* Spring Data JPA
* H2 Database
* JUnit 5
* Mockito
* MockMvc
* Maven

## Objetivo

Praticar testes unitários e testes da camada web utilizando JUnit 5, Mockito e MockMvc em uma API REST simples.

## Funcionalidades

* Buscar produto por ID
* Criar produto
* Atualizar produto
* Remover produto

## Testes

* Testes unitários da camada Service
* Testes da camada Controller com MockMvc
* Testes de exceções e validações de comportamento
